# 📝 Python To-Do List

A simple command-line To-Do List application built using Python. It allows users to add, view, and delete tasks easily.

## 🚀 Features

* Add tasks
* View tasks
* Delete tasks
* Simple menu-driven interface

## 🛠️ Requirements

* Python 3

## ▶️ Run the Program

python todo.py

## 💡 Usage

1. Add Task
2. View Tasks
3. Delete Task
4. Exit

## 📌 Future Improvements

* Save tasks permanently
* Add GUI
* Add deadlines
